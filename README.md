# termnake

Змейка в терминале. Работает на macOS, Linux и Windows.

## Запуск

Требуется Rust с поддержкой edition 2024 (1.85+).

```bash
git clone https://github.com/simatheone/termnake.git
cd termnake
cargo run --release
```

## Управление

В меню выбора уровня:

| Клавиша | Действие |
|---|---|
| `↑` `↓` / `w` `s` | Переместить курсор |
| `Enter` | Выбрать пункт |
| `Esc` / `q` | Выход |

В игре:

| Клавиша | Действие |
|---|---|
| `w` `a` `s` `d` / стрелки | Сменить направление |
| `Пробел` | Пауза / продолжить |
| `Esc` / `q` | Выход |

После проигрыша:

| Клавиша | Действие |
|---|---|
| `r` | Новая игра на том же уровне |
| `m` | Меню выбора уровня |
| `Esc` / `q` | Выход |

## Правила

- `@` — голова, `o` — тело, `*` — еда, `#` — стены.
- Каждая съеденная еда даёт +1 к счёту и ускоряет змейку на 10 мс на ход, но не быстрее предела уровня.
- Удар о стену или собственное тело — конец игры.
- Заполнил всё поле — победа.

## Уровни сложности

| Уровень | Старт, мс на ход | Предел, мс на ход |
|---|---|---|
| Easy | 200 | 100 |
| Medium | 150 | 70 |
| Hard | 100 | 30 |

Чем меньше мс на ход, тем быстрее змейка.

## Настройка

В `src/config.rs`:
- размер поля — `WIDTH`, `HEIGHT`;
- скорость уровней — `*_START_TICK`, `*_MIN_TICK`.

## Структура

- `src/main.rs` — игровой цикл, отрисовка, ввод;
- `src/snake.rs` — логика змейки;
- `src/terminal.rs` — `TerminalGuard`: raw-режим и альтернативный экран, восстанавливаются при выходе и панике;
- `src/config.rs` — размеры поля и скорость уровней;
- `src/menu.rs` — уровни сложности и меню выбора.
